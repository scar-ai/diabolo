# Diabolo — Subscription Tiers

## Free

Entry-level plan. No credit card required.

| Limit            | Value                    |
| ---------------- | ------------------------ |
| Concurrent tasks | 1                        |
| Session duration | ≤ 30 minutes             |
| Session cooldown | 5 hours between sessions |
| Active projects  | 1                        |
| Collaborators    | —                        |
| Organisations    | —                        |

**Included**

- 1 concurrent running session
- 1 active project at a time

**Not included**

- Collaboration or shared projects
- Organisation creation
- Scheduled / cron runs
- Codex as an LLM provider
- Priority execution queue

---

## Pro

For small teams that need parallel tasks and collaboration.

| Limit                     | Value     |
| ------------------------- | --------- |
| Concurrent tasks          | 10        |
| Session duration          | Unlimited |
| Session cooldown          | None      |
| Active projects           | 3         |
| Collaborators per project | 10        |
| Organisation member limit | 5         |

**Included**

- 10 concurrent tasks
- 3 projects with up to 10 collaborators each
- Organisation creation (up to 5 members)
- Scheduled / cron runs
- Codex as an LLM provider
- Priority execution queue

---

## Max

For growing organisations with large-scale automation needs.

| Limit                     | Value     |
| ------------------------- | --------- |
| Concurrent tasks          | 20        |
| Session duration          | Unlimited |
| Session cooldown          | None      |
| Active projects           | 20        |
| Collaborators per project | 50        |
| Organisation member limit | 50        |

**Included**

- 20 concurrent tasks
- 20 concurrent projects with up to 50 collaborators each
- Organisation creation (up to 50 members)
- Scheduled / cron runs
- Codex as an LLM provider
- Priority execution queue
